## Dust-Measuring-Device
# วัตถุประสงค์
- เพื่อพัฒนาอุปกรณ์ Arduino สำหรับตรวจวัดปริมาณฝุ่นในอากาศ โดยใช้ไมโครคอนโทรลเลอร์ Arduino ทำงานร่วมกับเซนเซอร์ตรวจจับฝุ่น เพื่อให้สามารถวัดและแสดงค่าฝุ่นในบริเวณต่าง ๆ ได้แบบเรียลไทม์ ทั้งนี้เพื่อให้ผู้ใช้งานสามารถประเมินคุณภาพอากาศในพื้นที่ได้สะดวกและเข้าใจง่าย
