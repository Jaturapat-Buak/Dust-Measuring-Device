# **Physical Computing Project 2024 - IT KMITL 🔬**
## Dust-Measuring-Device
# วัตถุประสงค์
- เพื่อพัฒนาอุปกรณ์ Arduino สำหรับตรวจวัดปริมาณฝุ่นในอากาศ โดยใช้ไมโครคอนโทรลเลอร์ Arduino ทำงานร่วมกับเซนเซอร์ตรวจจับค่าฝุ่น เพื่อให้สามารถวัดและแสดงค่าฝุ่นในบริเวณต่าง ๆ ได้แบบเรียลไทม์ ทั้งนี้เพื่อให้ผู้ใช้งานสามารถประเมินคุณภาพอากาศในพื้นที่ได้สะดวกและเข้าใจง่าย

# รายละเอียด

จะรับค่าฝุ่นจากเซนเซอร์ในช่วงเวลาหนึ่งแล้วนำค่ามาเขียนลงใน Google Sheet

---

## 📥 INPUT
- เซนเซอร์ GP2Y1010AU0F สำหรับตรวจจับค่าฝุ่นในอากาศ  

## 📤 OUTPUT
- แสดงผลข้อมูลค่าฝุ่นบน **Google Sheet** แบบเรียลไทม์  

---

## การทำงาน
1. เซนเซอร์ตรวจจับค่าฝุ่นและส่งสัญญาณอนาล็อกไปยัง Arduino  
2. Arduino ประมวลผลข้อมูลและแปลงค่าให้อยู่ในรูปที่เข้าใจง่าย (μg/m³)  
3. ข้อมูลถูกส่งขึ้น Google Sheet ผ่าน Wi-Fi เพื่อเก็บและวิเคราะห์  
4. ผู้ใช้สามารถดูข้อมูลย้อนหลังได้ทุกที่ทุกเวลา
